## 2. 四条核心逻辑 → 因子

1. **驱动**：被动平仓 + 恐慌主动去杠杆；跌停阻塞导致抛压外溢  
   → 融资 Top100 跌停/开板/新增跌停  
2. **GJD**：拖优先于拉；允许再跌 2–3 点完成筹码交换；真反转靠产业  
   → ETF 放量/溢价 + `DRAG_NOT_LIFT` + 反弹性质标注  
3. **传导**：沪深300 → 创业板 → 中证1000  
   → 分时形态滞后复制相似度  
4. **右侧**：带头板块与指数共振才有效；外盘波动降 + CapEx/财报落地减科技压制  

## 3. 抄底节奏（映射 stage，非自动交易）

| 阶段 | 行为纪律 | 对应周期/救援阶段 |
|---|---|---|
| 大跌当日 | 不猜底，只看是否托住流动性 | S1/S2 · PROTECT_INDEX |
| 次日/周一 | 宽基分档试探（300/-0.5、创业/-1、1000/-2 为叙事档位） | S2 · STABILIZE_BROAD |
| 右侧确认 | 板块+指数共振后再看弹性 | S4 候选 · ROTATE_QUALITY / RELEASE_ELASTIC |

## 4. 对本轮定位的粗判（需 LIVE 校准）

- 全球：科技自 META 硬件相关高点起美/韩/A 半导大量级回撤（用户称 30%+，以数据校准）

- 07-21 上午开板率跳升 → 偏向 **S2 摸底尾声 / 进入 S3 磨底**，**非** S4 中周期确认
